This repository documents my journey through various CTF competitions, and practice platforms. Each writeup breaks down the vulnerability, exploitation steps, and key takeaways — both as a personal reference and to help others learning offensive security.

Write-ups for intentionally vulnerable applications and OWASP-based challenges.

### CTF Competitions

Write-ups from CTF competitions and security events.

More categories and platforms will be added as I progress.
